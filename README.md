# Datheon Python Internship

This repository contains four Python projects developed as part of my Python Internship at Datheon. These projects demonstrate practical Python programming concepts, problem-solving skills, and automation techniques.

## Task 1 – Hangman Game

A Python-based word guessing game where players try to guess a hidden word one letter at a time within a limited number of attempts.

**Key Features:**
- Random word selection
- Letter-by-letter guessing
- Tracks correct and incorrect guesses
- Displays win or lose results

## Task 2 – Stock Portfolio Tracker

A Python-based application that helps users manage stock investments by recording stock names, quantities, and purchase prices. It calculates total investment and generates a portfolio summary.

**Key Features:**
- Add stock details
- Track quantities and prices
- Calculate total investment
- Generate and save portfolio summaries in CSV format

## Task 3 – Rule-Based Chatbot

A Python-based chatbot that interacts with users by providing predefined answers using keyword matching and stored FAQs.

**Key Features:**
- Interactive conversations
- Predefined responses
- Keyword-based matching
- JSON-based FAQ storage
- Handles unknown questions

## Task 4 – Automated File Organizer & Cleanup Utility

A Python-based utility that automatically organizes files into category folders based on their file extensions.

**Key Features:**
- Scans files in a directory
- Identifies file extensions
- Creates category folders automatically
- Organizes documents, images, videos, archives, and code files

## Technologies Used
- Python
- CSV and JSON
- OS and Shutil Modules
- File Handling
- Functions, Loops, and Conditional Statements
