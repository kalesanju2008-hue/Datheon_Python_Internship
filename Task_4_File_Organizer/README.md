# Task 4 – Automated File Organizer & Cleanup Utility

## Description
A Python-based utility that automatically organizes files in a selected directory based on their file extensions.

The program scans the specified directory, identifies file types, creates category folders when needed, and moves files into their respective folders. This helps keep directories clean and organized while reducing manual file management.

## Features
- Scan files in a selected directory.
- Identify file extensions automatically.
- Create category folders when they do not exist.
- Organize documents, images, videos, archives, and code files.
- Move files into their appropriate folders.
- Reduce manual effort in organizing files.

## Technologies Used
- Python 3
- OS Module
- Shutil Module
- File Handling
- Conditional Statements
- Loops and Functions

## Project Files
- `organizer.py` – Main file organization program.
- `README.md` – Project documentation.

## Installation
1. Install Python 3.
2. Download or clone this repository.
3. Open the terminal in the project folder.

No external Python packages are required.

## How to Run

Run the following command:

`python organizer.py`

Follow the program instructions to select the directory you want to organize.

## Output
The program creates category folders and moves files into the appropriate folders based on their extensions.

## Note
Always test the organizer on a sample folder containing copied files before using it on important personal files.
