# Task 4 – Automated File Organizer & Cleanup Utility

## Description
A Python-based utility that automatically organizes files in a selected directory based on their file extensions. It creates category folders and moves files into the appropriate folders to keep directories clean and organized.

## Features
- Scans files in a directory
- Identifies file extensions
- Automatically creates category folders
- Organizes documents, images, videos, archives, and code files
- Reduces manual file management

## Technologies Used
- Python
- OS Module
- Shutil Module
- File Handling
- Conditional Statements

## How to Run
Run the following command:

`python organizer.py`
