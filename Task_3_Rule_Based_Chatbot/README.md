# Task 3 – Rule-Based Chatbot

## Description
A Python-based chatbot that interacts with users by providing predefined answers to their questions. It uses keyword matching and stored FAQs to generate suitable responses.

## Features
- Interactive conversations
- Predefined question-and-answer responses
- Keyword-based matching
- FAQ storage using JSON
- Default response for unknown questions

## Technologies Used
- Python
- JSON
- Conditional Statements
- Loops and Functions
- String Handling

## How to Run
Run the following command:

`python chatbot.py`
