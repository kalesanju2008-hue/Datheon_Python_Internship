# Task 2 – Stock Portfolio Tracker

## Description
A Python-based application that helps users manage their stock investments by recording stock names, quantities, and purchase prices. It calculates the total investment and generates a portfolio summary.

## Features
- Add stock details
- Track stock quantities and prices
- Calculate total investment
- Generate portfolio summary
- Save data in a CSV file

## Technologies Used
- Python
- CSV Module
- Dictionaries
- Functions and Loops
- File Handling

## How to Run
Run the following command:

`python portfolio.py`
